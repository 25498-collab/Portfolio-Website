# Portfolio Website

A Vite + React portfolio site ready to deploy to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Push this project to GitHub.
2. In GitHub, open the repository and go to Settings > Pages.
3. Set the source to GitHub Actions.
4. Commit the workflow in this repo and push.
5. After the workflow runs, your site will be available at:

```text
https://<your-github-username>.github.io/<your-repository-name>/
```

## Repo-ready setup included

- Vite configured for static hosting with relative asset paths
- GitHub Pages deployment script
- GitHub Actions workflow for automated deployment
- Clean project metadata for normal GitHub hosting
